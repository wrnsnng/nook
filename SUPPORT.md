# Support

## Using Nook

Before filing a report:

1. Confirm you are using the latest signed release.
2. Move `Nook.app` to `/Applications` and remove duplicate copies.
3. Review Microphone, Speech Recognition, and Screen & System Audio Recording
   access in **System Settings → Privacy & Security**.
4. Quit and reopen Nook after changing Screen & System Audio Recording access.
5. Check the [README](README.md) and [privacy guide](docs/PRIVACY.md).

Use a GitHub issue for reproducible bugs and feature requests. Include Nook,
macOS, Mac model, meeting provider, and browser/app versions when relevant.
Redact window titles, participant names, transcripts, organization details, and
filesystem paths that identify you.

## What not to post publicly

Do not include recordings, transcripts, credentials, crash logs containing
meeting content, signing material, or personal information. Report security and
privacy vulnerabilities through [SECURITY.md](SECURITY.md).

## Project scope

Community support is best-effort. Maintainers cannot provide legal advice about
recording consent, guarantee recognition quality for every language or audio
environment, or support modified binaries as if they were official releases.
