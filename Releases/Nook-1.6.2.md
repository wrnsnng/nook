## Nook 1.6.2

This compatibility release rebuilds Nook with the stable macOS 26 toolchain for
reliable first launch on Tahoe.

- Built against the stable macOS 26 SDK instead of the macOS 27 beta SDK.
- Developer ID signed, notarized, and stapled for Gatekeeper.
- Adds a stable latest-download artifact for the Nook website.
- Keeps historical Sparkle update artifacts separate from the public release.
