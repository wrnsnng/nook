# Nook 1.4

Nook can now keep itself up to date.

## New

- Native, signed over-the-air updates powered by Sparkle.
- A dedicated Updates pane with manual checks and automatic-update controls.
- “Check for Updates…” in both the Nook menu and the application menu.

## Trust and privacy

- Update feeds and archives are signed with the Common Tools Co. EdDSA key.
- Every app build remains Developer ID signed, notarized by Apple, and verified before installation.
- The updater does not change Nook’s local-first meeting data path.

Nook 1.4 is the first version with the updater built in. Install this release manually once; later releases can arrive automatically.
