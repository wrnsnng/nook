# Nook 1.24.0

Nook can name the people in a Zoom call, and a large library opens in a moment.

**Speakers**

- Nook can name the people in a Zoom call. With *Name speakers from Zoom* on in Settings, it reads participant names and Zoom's active speaker while it records, and puts a name to a voice when the match is clear. This works with the Zoom desktop app only, not Zoom in a web browser. Naming a voice by hand now offers the people from the call, or the calendar invitees, with one click.
- Several people sharing one Zoom name, such as a meeting room, are kept apart as *Boardroom · voice 1*, *Boardroom · voice 2*.
- Voices Nook cannot identify are labelled *Unclear · voice 1* instead of *Speaker 1*, which read like one more person in the meeting. Older notes are unchanged.

**Library**

- A large library shows its notes, and lets you read them, within a moment of opening, instead of waiting for every transcript to load.

**Windows**

- Nook stays in the Dock and ⌘-Tab while any of its windows is open, including Settings, and goes back to the menu bar only when the last one closes.

Nook remains local-first. This release adds no telemetry, network service or
remote model.
