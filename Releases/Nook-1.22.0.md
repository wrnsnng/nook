# Nook 1.22.0

Folders that live in Finder, summaries you can keep editing, and a calmer,
more consistent look.

**Organise and edit**

- Group notes into folders. A Folders section in the sidebar lists them, and
  choosing one shows only its notes. Each folder is a real folder in your notes
  folder on disk: creating, renaming or deleting one in Nook does the same in
  Finder, and folders made in Finder appear in Nook. Move a note with Move To
  in its menu or by dragging it onto a folder, and its Markdown file moves
  too. File, New Folder (Shift-Command-N) makes one. Deleting a folder moves
  its notes back to the library and never deletes them.
- Keep working on a meeting's notes in Nook. The gist, key points, decisions,
  action items and open questions are editable right on the Notes tab: click
  and type, press Return for a new item, and changes save on their own. A
  ticked action item stays ticked when you reword it. Regenerate Summary asks
  before replacing anything you have edited.

**A tidier window**

- The toolbar over a note now holds only that note's actions, Share and More,
  as in Notes. New Note, Ask Your Library and Create Weekly Digest sit over the
  list, since they act on the whole library.
- Open actions are no longer shown in the sidebar. Action items stay in each
  note.
- Type is calmer and more consistent: the system text styles throughout, bold
  only for page titles, and regular weight for rows, status and metadata. The
  notch uses the same sizes as the rest of the app.

**Fixes**

- Meeting reminders from your calendar arrive reliably. The heads-up before
  an event could be missed by a few seconds and then never came.
- Summaries of new recordings are kept again. A library reload while the
  summary was being written could discard it and show "changed while
  regeneration ran".
- A summary that cannot be saved is explained once, in the note, not also in
  a banner.
- While recording, the menu bar shows only the record or pause symbol, rather
  than a second clock beside the notch's.
- Hiding the notch during a recording shows the small pill beside the camera
  again, instead of leaving it folded inside the camera housing where it could
  not be clicked.
- Settings, Keyboard lines up again.

Nook remains local-first. Folders are ordinary folders in your notes folder,
and edits are written to the same Markdown files on this Mac. This release
adds no telemetry, network service or remote model.
