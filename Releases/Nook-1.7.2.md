# Nook 1.7.2

Long meetings now record all the way to the end.

- Nook keeps your Mac awake while it is recording. A Mac that went to sleep
  ended the recording with no warning, which is why meetings you were only
  listening to stopped after about twenty minutes. Only sleep is deferred, not
  the display, so the screen still switches off as usual.
- If recording is interrupted for any other reason, Nook now finishes the
  meeting and saves what it captured instead of appearing to keep going.
- Every download now publishes a checksum, so you can confirm you received the
  file Nook actually built.
